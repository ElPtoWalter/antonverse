# Antonverse v40 · arreglo definitivo de nombres en clave

Versión basada en v39. No incluye modo online ni Supabase.

Corrección:
- El desbloqueo de nombres ahora es más flexible con signos de puntuación.
- Por ejemplo, `ha` también reconoce el nombre canónico `ha!`.
- Si pegas una lista y hay algo mal escrito, ahora la web enseña qué texto no ha reconocido.
- Los nombres guardados en localStorage se limpian y se pasan a nombres canónicos válidos.
- Se evita que un nombre raro en localStorage pueda dejar el contador en un estado confuso.
