# Antonverse v36 · importar nombres en bloque

Versión basada en v35. No incluye modo online ni Supabase.

Mejora nueva:
- Ahora los nombres en clave se pueden desbloquear uno a uno o en bloque.
- Puedes copiar la lista de nombres descubiertos desde un móvil.
- En otro móvil, pegas esa lista en "Importar descubiertos".
- La web detecta los nombres válidos y los añade de golpe.
- Los repetidos no duplican progreso.
- Los no válidos se ignoran.
- Si se completa la lista, se abre el candado final.

Mantiene:
- selector de radio arreglado;
- 52 nombres en clave finales;
- cuenta atrás;
- código DulceSweet;
- tienda;
- ruleta;
- galería ampliada;
- ou-yeah real;
- bocina de error;
- candado final "Contratar a Steisy".

Para subir:
1. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz.
2. No hace falta tocar `assets` si ya tenías fotos y audios subidos.

El QR de las camisetas no cambia.
