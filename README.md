# Antonverse v41 · animación épica para revelar la putada final

Versión basada en v40. No toca el QR ni mete modo online.

## Qué añade
- Animación especial al desbloquear el último nombre en clave.
- Se oscurece la web y aparece una escena de candado/cadenas.
- Efecto visual de rotura con “PAAAAAM”.
- Mensaje de desbloqueo de la putada final.
- Botón para ir a verla y cierre automático del overlay.
- Si queréis, podéis pulsar otra vez la tarjeta de la **Putada final** ya desbloqueada y la animación se repite.
- Se puede cerrar también tocando fuera o con `Esc`.
